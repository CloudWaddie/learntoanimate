# Learn to Animate

An interactive course on crafting web animations that feel right — theory, code, and taste.

19 lessons across 4 modules, every concept taught through a live playground: a bézier easing editor, spring physics lab, stagger orchestrator, layout/FLIP demos, gesture sandbox, scroll-driven effects, and a canvas particle studio.

## Stack

- Next.js 15 (App Router) + React 19
- Tailwind CSS v4
- Motion (`motion/react`) for all component animation
- Canvas for particles, WAAPI for easing previews

## Run

```sh
npm install
npm run dev
```

Open http://localhost:3000 — landing page, then `/course` for the lessons.

Inspired by the craft of [animations.dev](https://animations.dev), [whimsy.joshwcomeau.com](https://whimsy.joshwcomeau.com), and [emilkowal.ski](https://emilkowal.ski).
